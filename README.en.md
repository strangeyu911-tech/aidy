# Aidy

A personal AI assistant that runs across Windows and WeChat. Aidy keeps context over time, notices task and time-related state, and can proactively show up when it is useful. Within the tools and workspace you authorize, it can help move real work forward rather than only offering suggestions.

## What Aidy is for

Most AI assistants begin only after you open them and type a prompt. Aidy is built for a more continuous role: it can work through the WeChat conversations you already use, retain relevant context around a workspace, and follow up through reminders, check-ins, and checkpoints.

## What Aidy can do today

- Carry forward context from workspaces, timelines, and local diaries instead of treating every message as an isolated chat.
- Receive and reply to WeChat messages, including supported files and media.
- Offer reminders, random check-ins, and checkpoint-based follow-up with quiet-time, deduplication, and expiry boundaries.
- Use project-native tools and optional local MCP services within the permissions you give it.
- Connect to WorkBuddy (the recommended default), Codex, and compatible or custom APIs.
- Provide a Windows desktop control center for model connections, WeChat sign-in, service controls, status, configuration, and diagnostics.

## Getting started

Use the Windows control center to connect and verify a model provider, sign in to WeChat, and start Aidy. You can then bind a workspace to a chat when you want the Agent to work with continuing project context. For installation, supported commands, current limitations, and security boundaries, see the Chinese [README.md](./README.md) and [INSTALL.md](./INSTALL.md).
