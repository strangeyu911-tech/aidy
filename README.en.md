# CyberBoss + WorkBuddy

The canonical README for this fork is the Chinese [README.md](./README.md).

This repository is a derivative work based on [WenXiaoWendy/cyberboss](https://github.com/WenXiaoWendy/cyberboss). It focuses on the Windows + WeChat + WorkBuddy workflow, including the CodeBuddy ACP runtime adapter, desktop setup, model verification, message-delivery hardening, proactive supervision queue boundaries, and release tooling.

For the current installation path, limitations, security boundaries, and upstream attribution, see [README.md](./README.md) and [INSTALL.md](./INSTALL.md).
