# Aidy（艾迪）

Aidy 是一个运行在 Windows 与微信中的个人 AI 助手：它能持续理解上下文、感知时间与任务状态，并在合适的时候主动出现；在你授权的工具与工作区边界内，它也能帮助推进实际事务，而不只给出建议。

## Aidy 能做什么

- 将 workspace、时间线和本地 diary 中的相关信息带入后续协作，而非把每条消息当作孤立对话。
- 通过微信接收和回复日常消息，并处理支持的文件或媒体。
- 借助 reminder、随机 check-in 和 checkpoint 主动提醒或跟进，同时遵守静默时段、去重和过期边界。
- 在获得授权后，使用项目原生工具和可选本地 MCP 服务帮助完成事情。
- 默认推荐 WorkBuddy，也可接入 Codex、兼容接口和自定义 API。
- 通过 Windows 桌面控制中心管理模型连接、微信登录、服务启停、状态、配置与诊断。

完整的产品说明、安装步骤、当前限制与隐私边界请见 [README.md](./README.md) 和 [INSTALL.md](./INSTALL.md)。
