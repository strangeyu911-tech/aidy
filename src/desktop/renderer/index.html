完整配置指南

使用 WorkBuddy 连接 AI 模型

普通用户优先走这条推荐路径。

选择运行方式→填写模型→测试→激活
  1. 1
    安装并登录 WorkBuddy

    推荐普通用户优先使用 WorkBuddy。安装后，在 WorkBuddy 中完成登录。

    账号与兼容性说明

    登录属于当前 Windows 用户；外部登录、退出、切换账号或升级版本后，可能需要重新测试配置。

  2. 2
    点击“新增配置”

    回到上方 AI 引擎区域，点击右上角“新增配置”。

  3. 3
    选择运行方式

    运行引擎选择“WorkBuddy（推荐）”。

  4. 4
    选择模型

    点击“刷新模型”获取当前账号可用模型。下拉菜单显示模型名称，但保存和测试使用对应的真实模型 ID；Auto 会映射为 auto。只有在目录没有返回时，才在高级设置中自定义模型 ID。

  5. 5
    保存并测试连接

    点击“保存并测试连接”，确认当前模型和本机连接确实可用。

  6. 6
    测试通过后激活

    只有通过测试的配置才能激活。激活后，它才会成为艾迪当前使用的 AI 配置。

我使用 API Key 或其他兼容引擎

已有 API Key 时可选择“内置 API”；Codex、Claude Code 与 OpenCode 面向已经熟悉这些工具的用户，其中 OpenCode 仍属于高级实验选项。ChatGPT 等产品订阅不等于 API Key。

查看或关闭本指南不会创建、修改、测试或激活任何配置。
